## What I think about AI in software engineering today

AI is unmatched for ripping through boilerplate and syntax lookups, but it frequently hallucinates subtle logical flaws that make debugging twice as tedious. It speeds up the typing part of programming without genuinely understanding system architecture or context. Right now, it works best as an eager junior developer whose every commit needs thorough code review.

## Where software engineering will be in 5–10 years

The core job will shift almost entirely from typing code to specifying requirements, edge cases, and architectural constraints. Writing raw boilerplate by hand will largely disappear, replaced by autonomous agents managed by engineers acting as system architects. True engineering value will center on verification, fault tolerance, and knowing what to build rather than how to type it out.

## My hot take on AI

AI doesn’t make bad developers good; it just helps them generate catastrophic technical debt at record speed.
